# ISSHUE Super Admin Frontend

## Installation

```bash
npm install
```

## Running the Application

```bash
npm start
```

The application will run on http://localhost:3000

## Features

### Sales Module
- **New Sale**: Create new sales with multiple items
- **Manage Sale**: View, edit, and delete existing sales
- **POS Sale**: Point of sale interface for quick sales
- **Invoice Text**: Configure invoice text settings

## Backend API

Make sure the backend server is running on http://localhost:5000
